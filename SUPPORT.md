# Support

## Usage questions

Open a GitHub Discussion for questions about using `Ahr.Foundation`, API design, or integration
patterns.

## Bugs and feature requests

Search existing issues before opening a new one. Include the package version, target framework, a
minimal reproduction, expected behavior, and actual behavior.

## Security reports

Do not open a public issue for a suspected vulnerability. Follow the private reporting process in
[SECURITY.md](SECURITY.md).

Commercial support is not included with the open-source package.
