# Security policy

## Supported versions

Security fixes are applied to the latest stable `0.x` release. Pre-release and older `0.x` versions receive fixes at the maintainers' discretion.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for `AHRConsulting/Ahr.Foundation`. Do not disclose suspected vulnerabilities in public issues. Include affected versions, reproduction steps, impact, and any proposed mitigation. The maintainers will acknowledge a report, assess it, and coordinate disclosure through the private report.
